# GeographicLib C library (geodesic routines)

Unmodified `geodesic.c`, `geodesic.h` and `LICENSE.txt` from
[geographiclib-c](https://github.com/geographiclib/geographiclib-c),
version 2.2, by Charles Karney, under the MIT license (see `LICENSE.txt`).

Used by `orthodrome_ext` to solve the direct and inverse geodesic problems on
the WGS84 ellipsoid.

Reference: C. F. F. Karney, Algorithms for geodesics, J. Geodesy 87, 43-55
(2013), https://doi.org/10.1007/s00190-012-0578-z
